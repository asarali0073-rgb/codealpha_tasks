# ColdAlpha Internship -- Machine Learning Projects

Welcome to my ColdAlpha Internship Projects Repository!

This repository contains three Machine Learning and Deep Learning
projects completed as part of my ColdAlpha Internship.

## Projects

### Task 01 -- Credit Scoring Model

-   **Dataset:** Give Me Some Credit (Kaggle)
-   **Objective:** Predict the credit risk of loan applicants.
-   **Target:** `SeriousDlqin2yrs`
-   **Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib,
    Seaborn.

### Task 02 -- Breast Cancer Prediction

-   **Dataset:** Breast Cancer Wisconsin Dataset (Kaggle)
-   **Objective:** Predict whether a breast tumor is Benign or
    Malignant.
-   **Target:** `diagnosis` (B = Benign, M = Malignant)
-   **Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib,
    Seaborn.

### Task 03 -- Handwritten Character Recognition

-   **Dataset:** EMNIST Balanced
-   **Objective:** Recognize handwritten characters using a
    Convolutional Neural Network (CNN).
-   **Classes:** 47
-   **Framework:** TensorFlow / Keras.
-   **Technologies:** Python, TensorFlow, Keras, NumPy, Pandas,
    Matplotlib.
